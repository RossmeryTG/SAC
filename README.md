# Mapa ONA — Servicio al Cliente (datos simulados)

Mapa interactivo de Organizational Network Analysis (ONA) construido sobre datos **simulados**
de la división Servicio al Cliente. Muestra la red de "a quién recurro para obtener información
y avanzar con mi trabajo", con tres patrones detectados automáticamente: **conectores**,
**cuellos de botella** y **aislados**.

- Grafo de fuerza interactivo (zoom, arrastre de nodos, búsqueda).
- Filtros por área, sección, nivel y unidad.
- Comparación entre estructura formal (área) y comunidades reales detectadas en la red.
- Panel de detalle con métricas por colaborador.

## Datos
Los colaboradores están **anonimizados** ("Colaborador 0001", "Externo 01", etc.) y las
relaciones entre ellos son **simuladas**: no representan respuestas ni personas reales.
Este proyecto es material de práctica/demo de la metodología ONA.
